# AI Architectural Context

## 1. Legacy-Audit Ergebnisse

### Hardcodierte Werte und "Scam-Signale" (Zur Restlosen Eliminierung)
- **Preis-Signal:** Hardcodierte "ab 50€" im `layout.tsx` (Description), `page.tsx` (Title & Hero), `PricingCard`. Zukünftig: Typsicher ab "59 Euro" via Datenmodell.
- **Farben (Scam-Signal):** Dominante Verwendung von Alarm-Rot (`#B91C1C`) für Buttons, Icons, Hover-Effekte (`--color-brand`). Wird komplett blockiert und durch Navy/Emerald ersetzt.
- **Telefonnummern:** Hardcodierte `06441 123 456` überall im Code (`page.tsx`, `StickyHeader.tsx`, `EmergencyCTA.tsx`).
- **Ortsnamen:** Hardcodiert "Wetzlar", "Gießen", "Marburg", "Lahn-Dill-Kreis".
- **Hero-Aussagen:** "Wir öffnen Ihre Tür in Wetzlar beschädigungsfrei in unter 25 Minuten"

### Architektur-Status
- `lib/localData.ts` beinhaltet bereits ein umfangreiches Array von Städten inkl. Koordinaten und Preisen. Dies muss teilweise nach `/lib/data/areas.ts` und `pricing.ts` refactored werden.
- Tailwind v4 Custom Properties System ist aktiv (`app/globals.css`).

## 2. Die neue Marken-Identität (Premium Emergency Security)

- **Tonalität:** Beruhigend, hochprofessionell, transparent, sofort handlungsbereit. Kein Alarmismus.
- **Zielgruppe:** 80% Mobile, Situation: Panik, ausgesperrt, Regen.
- **Brand Colors:**
  - Primary (Trust): Navy-Blau / Slate-Grau
  - Action/Urgency: Smaragdgrün / Signal-Orange (Nur für Call-CTA)
  - Surface: Off-White / Weiß
- **Typografie:**
  - Geometrische Sans-Serif (Inter) mit tabellarischen Zahlen (tabular-nums) für mathematische Präzision bei Preisen und Nummern.

## 3. Architektur-Richtlinien

- **Data-Source:** `/lib/data/*.ts`
- **SSOT:** Code ist die Source of Truth (kein externes CMS).
- **Abhängigkeiten:** Nur Formspree und Calendly.
- **SSR/CSR:** Hero Section muss zwingend Server Component sein (Ladezeitziel: LCP < 1.2s). Sticky CTA Client Component.
